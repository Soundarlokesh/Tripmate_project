# Destination data

`destinations/` holds the destination data pack supplied with the assessment, unmodified:
`tokyo.txt`, `reykjavik.txt`, `bangkok.txt`, `barcelona.txt` (5 sections each: Visa & Entry, Best Time to
Visit, Local Customs, Packing Tips, Safety & Health) and the pack's own `README.txt`.

This is the only source of destination-guide facts. The pack states that it is a simplified reference
dataset, not authoritative or current travel or visa advice.

`index/` (git-ignored) is generated by `python -m scripts.ingest_data`.
